# Lesson App

A small interactive lesson tracker built with React and Vite. It includes a progress bar, locked and unlocked lessons, and a detailed lesson view for learning HTML topics.

## Features
- lesson cards with completion status
- progress tracking across all lessons
- locked lesson flow
- simple monochrome styling
- responsive layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
